## Proyectos destacados

### FLOODSHADOW

Beta que reúne evidencia de lluvia y contexto territorial de Guayaquil para explorar qué se conoce y qué necesita revisión.

- **Tecnologías:** JavaScript, React, MapLibre GL, Turf, Vite y Node.js; Python para la preparación geográfica.
- **Funciones:** mapa territorial, consulta de lluvia, escenarios guardados, hallazgos con fuentes e historial de revisiones e informes PDF.
- **Participación:** proyecto del equipo **3Jota** para Hack2Impact 2026.
- **Alcance:** beta de evidencia local; los escenarios son simulaciones. No emite alertas oficiales ni probabilidades calibradas de inundación.
